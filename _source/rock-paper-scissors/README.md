# Rock Paper Scissors

A very fair game. Select a move, play, and discover the opponent's interpretation of the rules.

Hands are made entirely from CSS shapes. The opponent always reveals a finger gun, followed by “Skill issue.” No backend, scoring, or runtime dependencies.

Run `npm start` to preview at http://localhost:8070. Run `npm test` for round-flow tests. GitHub Actions tests and deploys `dist/` on main once GitHub Pages is configured to use Actions.
